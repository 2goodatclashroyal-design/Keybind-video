# KeyBind videos

This folder holds finished KeyBind MP4 clips for Buffer publishing.

## Upload

Upload each finished video into this folder with a unique filename, for example `keybind-demo-001.mp4`. Keep existing filenames unchanged while their posts are queued.

## Direct video link

For a video named `keybind-demo-001.mp4`, use:

`https://raw.githubusercontent.com/2goodatclashroyal-design/Keybind-video/main/videos/keybind-demo-001.mp4`

Use the raw file link, not the GitHub file-preview page. The video must remain publicly accessible until Buffer finishes publishing.

## Buffer

Attach the direct MP4 URL as a video asset on the KeyBind TikTok channel. Save a draft first and check that Buffer recognizes the video before scheduling or publishing.

Only finished videos intended for public distribution belong here.
